冒险岛提醒V1.0（永久版）— 游戏栏启动版
© 2026 老熊头

1. 在冒险岛游戏窗口中按 Win+G，打开并保持“捕获”面板可见。
2. 启动报警器，选择监控区域并开始监控。
3. 报警时，报警器只请求游戏栏“开始录制”。视频由 Windows 负责录制、编码和保存。
4. 请以游戏栏中的录制计时器确认启动成功。“已请求”不等于“已确认录制”。
5. 停止录制请直接操作游戏栏。退出报警器不会停止游戏栏录像。
6. 设置中“测试游戏栏启动”会实际请求录制，用于本机联调；“测试声音与通知”不会启动录制。
7. 保存位置以 Windows 游戏栏设置为准，软件中的文件夹按钮打开系统捕获目录。

本版不使用报警器自带的逐帧截图和视频编码循环。没有开始按钮、按钮禁用或界面不兼容时，会显示失败原因；不会发送开始/停止切换快捷键，也不会点击停止录制。
本版仅支持明确的简体中文、繁体中文和英文开始录制按钮。系统游戏栏需在你的电脑上测试是否能被访问及正常录像；未验证的系统版本可能无法识别按钮。
系统录制的目标、帧率、声音和保存位置由游戏栏设置决定，不再是报警器框选区域。请先确认游戏栏捕获的是冒险岛。
